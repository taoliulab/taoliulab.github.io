[MACS3 v3.0.4](https://github.com/macs3-project/MACS/releases/tag/v3.0.4) is now available. This release adds FRAG-format input support to HMMRATAC, fixes an issue that could produce `NaN` results in p-value statistics, and updates the API documentation.

MACS3 is our open-source peak caller for ChIP-seq and other DNA enrichment assays. Installation instructions and command references are available in the [MACS3 documentation](https://macs3-project.github.io/MACS/). For the full list of changes, see the [v3.0.4 release notes](https://github.com/macs3-project/MACS/releases/tag/v3.0.4).
